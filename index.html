Features

Built for privacy under real pressure

Protection enforced at the operating-system level — not cropped windows, not post-processing.

Capture-invisible windows

Uses WDA_EXCLUDEFROMCAPTURE on Windows and NSWindowSharingNone on macOS. Captured frames simply don't contain noscreen's pixels.

Global hotkeys & ghost typing

Show, hide, and type into the overlay without the app behind it ever losing focus or firing a blur event.

Embedded AI, protected

ChatGPT, Claude, and a native chat panel — all running as capture-protected webviews with anti-fingerprint patches.

Live speech-to-text

Continuous dictation via Windows Speech Recognition or Whisper, including system-loopback audio capture.

Click-through & opacity

Pass mouse events straight through to what's behind the overlay, and dial in exactly how transparent it looks.

Local-only history

SQLite-backed conversation history, stored on disk only — nothing is sent to a remote service.

Platform support

Where noscreen runs

Windows 10 (2004+) / 11
Primary target
Full feature set, including ghost typing and WASAPI loopback speech-to-text.
macOS 12+
Partial support
Core capture protection works; Windows-only features are stubbed.
Linux
Not planned
Wayland/X11 don't expose an equivalent capture-exclusion API.
